# Афиша культурных событий

Адаптивная статическая страница на HTML, CSS и JavaScript. Используются локальные изображения и шрифт из папки `assets`.

## Запуск

Откройте `index.html` в браузере. Для разработки можно запустить любой статический сервер, например:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000.

## Структура

- `index.html` — разметка страницы;
- `main.css` — стили и адаптивная сетка;
- `site.js` — календарь с переключением месяцев и выбором доступных дат;
- `assets/` — изображения, иконки и локальные шрифты.
